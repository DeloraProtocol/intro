Questions?
We’ve got answers.

How do I get an API key?

Register in the Partner Portal to get an API key. Keep the key on your backend.

Can I use the API without a key?

Most routing endpoints work without a key. Quote-related and other endpoints each have a limit of 200 requests per two hours. Transaction tracking requires an API key.

What happens if I exceed a rate limit?

The API returns a 429 response. See the rate limit documentation for details.

Can I set my own transaction fee?

Yes. Configure an optional integrator fee for your product. See the fee configuration guide.
