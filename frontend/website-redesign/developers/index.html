Questions?
We’ve got answers.

Do I need an API key?

Most routing endpoints work without a key. An API key enables higher rate limits and is required for transaction tracking. Keep it on your backend. See authentication and rate limits.

Can I use my own interface?

Yes. Use the API to build your own interface or embed the customizable React widget.

Does MCP sign or submit transactions?

No. MCP provides read-only tools and unsigned transaction data. Your wallet or backend signs and broadcasts transactions.

Can I configure an integrator fee?

Yes. Configure your integrator identifier and optional fee. See fee configuration.
